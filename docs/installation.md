# Installation

## Install Pocket Timer

You need `pipx` installed first. Then run:

```
pipx install pocket-timer
```

The command is the same on macOS, Linux and Windows.

## macOS

Open Terminal and run `pipx install pocket-timer`.

## Linux

Open your shell and run `pipx install pocket-timer`.

## Windows

Open PowerShell and run `pipx install pocket-timer`.

## Verify the installation

Run `pocket --version`. It prints the installed version number. If you see a version, you're ready:
head to [Your first session](getting-started.md#your-first-session).
